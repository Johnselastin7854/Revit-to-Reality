# Concept film

`revit-to-reality-film.html` is an 86-second real-time 3D film of the finished product (upload → streaming → MEP filters → explode/X-ray → AI assistant → walkthrough with minimap → digital twin). Open it in a browser and press **Play film**.

- Narration: Microsoft neural voice (en-US Jenny), embedded in the page. `narration.mp3` is the same track as a separate file for video editing.
- The building, counts and sensor data are illustrative.
- To record a video with sound: full screen, then Win + Alt + R (Xbox Game Bar).
